# Hospital Dashboard

A modern Hospital Management Dashboard built using React, Vite, and Tailwind CSS.

## Features

- Secure Login System
- Patient Management
- Doctor Dashboard
- Appointment Tracking
- Responsive UI Design

## Technologies Used

- React JS
- Tailwind CSS
- Vite
- React Router
- Lucide Icons

```bash
npm install
